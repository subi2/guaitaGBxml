guaitaGBXML

A gbXML file viewer and analyser that runs in the browser: explore the geometry, review construction data, compare models and check the data before simulation. A single HTML file, no server and no accounts.

Open the appUser guideGitHub

What it does

View the model and review its data

3D geometry, read-only

Geometry is read as it is: spaces, surfaces, openings and sun shadows. It is never modified.

Editable data

Names, types and constructions can be corrected, with undo and redo.

Envelope analysis

Areas, U-values from layers, WWR, compactness and CTE DB-HE1 limits by climate zone.

Validation

More than twenty warning codes to spot incomplete or inconsistent data before simulation.

Model comparison

Differences between two versions of the same project, element by element.

Large files

Models with tens of thousands of surfaces are processed in the background without freezing the interface.

Getting started

Three steps
  1. Open the app and drag a .xml or .gbxml file into the window, or use the open button.
  2. Explore the model with the views, the view cube and the sections.
  3. Review the envelope and validation, correct the data where needed and export the results.
